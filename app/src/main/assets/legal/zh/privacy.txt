HyperChanger 隐私政策

生效日期：2026年11月1日
最近修订：2026年11月1日

本政策说明本软件的数据用途、本地存储、联网场景和可用控制。HyperChanger 不要求注册账号，不以广告或商业行为分析为目的建立用户档案；联网功能仍会向相应服务方发送请求和必要参数。

## 1. 配置与本地文件

1.1 界面设置、作用域相关配置、图片、视频、歌词、预设、下载资源和缓存主要保存在设备本地。必要配置和素材会经框架远程偏好或本机接口提供给已启用的目标进程，以执行你选择的功能；这里的“远程偏好”是本机进程间同步，并非云同步。

1.2 导入、导出和分享由你选择的文件、二维码或系统分享渠道完成。本软件不将本地配置或个人素材自动上传为云端备份。接收文件的应用或你选择的云存储服务可能有独立的数据处理规则。

## 2. 功能运行时的数据

2.1 已启用的通知、动态岛、锁屏与媒体功能可能在目标进程内读取通知内容、应用信息、媒体标题、艺术家、专辑、时长、封面、播放状态及交通/取餐卡片信息，用于展示、匹配和交互。相关内容可能显示在锁屏或其他可见界面，请按需要控制显示范围。

2.2 授权日历权限并使用对应日程显示功能时，软件会读取事件标题、开始时间和全天状态等必要信息，供本机界面展示。应用列表用于作用域、目标应用选择及相关配置，不作为广告画像上传。

2.3 开启增强 OCR 后，待识别图像通过本机接口交给本软件内置的本地识别引擎，识别结果返回传送门。下载模型不需要上传待识别图像。目标应用原有的识别流程及你随后使用的服务仍受其自身政策约束。

## 3. 联网：音乐与动态内容

3.1 启用相关在线音乐功能后，会向所选歌词、曲目信息或封面服务发送标题、艺术家、专辑、时长、歌曲标识或资源地址等匹配参数。服务可能包括网易云音乐、QQ 音乐、酷狗、酷我、LRCLIB、AMLL/TTML 资源库、Apple Music/iTunes、MusicBrainz 及其 CDN 或镜像；实际请求取决于启用的功能和来源。

3.2 使用交通卡片图片、云端取餐规则等功能时，可能访问 HeyTap/ColorOS 等资源服务。交通素材的路径可能包含所选城市或地标名称，因而可能透露与行程有关的区域信息；云端规则请求可能包含 Android API 版本等客户端信息。不能将这些请求理解为完全匿名。

## 4. 联网：更新、资源与外部链接

4.1 检查更新、下载更新包、浏览贡献者及头像、获取在线设备预设或下载 OCR 模型时，会访问 GitHub Pages、GitHub/GitHub Raw、Gitee 或资源地址对应的服务。

4.2 应用启动时会刷新 BOSE 设备支持列表，优先访问 GitHub Pages，失败时尝试 Gitee；这是公共机型列表下载，不需要上传本机设备代号。关闭歌词或更新检查不等于关闭应用所有联网行为。

4.3 打开仓库、网站、群组或支持链接会将链接交给浏览器或相应应用，其网络和数据处理由该服务负责。主动贡献预设、提交 Issue 或分享日志时，你选择发送的内容可能向公众公开。

## 5. 网络信息与第三方处理

5.1 网络服务及中间 CDN、镜像可获知来源 IP、访问时间、请求路径、查询参数和 User-Agent 等连接信息；部分请求包含模块版本或 Android API 版本。IP 是网络连接信息，并非本软件主动加入的身份字段。第三方可依据其政策保留访问记录或在不同地区处理数据。

5.2 上述资源请求不以收集 IMEI、Android ID、通讯录或账号密码为目的。本软件不集成商业广告或用户行为统计 SDK，不出售个人数据；这不等于第三方平台不会记录访问，也不涵盖你主动提交的文件和反馈内容。

## 6. 权限与系统能力

6.1 Root 与框架能力用于环境检测、配置生效、目标进程操作、日志读取及用户选择的安装等功能，不仅限于重启作用域。启用模块即允许相关 Hook 在所选目标进程内运行，请谨慎授予作用域和超级用户权限。

6.2 文件选择用于你指定的图片、视频、歌词及预设导入导出；设置壁纸权限用于壁纸功能，应用查询用于应用选择，通知权限用于相关状态提示，日历权限用于日程展示，安装包权限用于你发起的更新安装，开机事件用于相应功能初始化。权限的具体可用性和撤销方式由系统管理。

## 7. 日志、保存与删除

7.1 诊断日志可能在本机生成；读取、导出或分享日志时，内容可能包含通知、包名、媒体信息及其他敏感数据。请先检查并移除凭证、账号、联系方式、行程等内容，再决定发送给谁。公开 Issue 的信息可能被搜索或复制，不要在其中提交秘密。

7.2 设置及导入文件通常保留至你修改、删除、清除应用数据或卸载；缓存也可能被系统清理。清除数据或卸载通常会移除应用私有数据，但不保证物理不可恢复，也不会自动删除公共目录导出文件、其他目标应用缓存、框架保存的副本或第三方服务记录；这些需分别管理。

## 8. 你的选择与政策更新

8.1 可关闭不需要的功能、撤销系统权限、停用作用域或卸载本软件。若需阻止全部网络连接，请使用系统提供的网络控制或在离线环境使用，并接受联网功能不可用；关闭某一个开关不会立即终止其他功能或已发出的请求。

8.2 本政策随功能变化更新，并在本页标注修订日期。隐私问题可通过 https://github.com/ColdP/HyperChanger 的 Issue 反馈；该渠道通常公开，请勿提交敏感个人信息。

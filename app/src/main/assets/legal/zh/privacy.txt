HyperChanger 隐私政策

生效日期：2026年11月1日
最近修订：2026年11月13日

本隐私政策用于说明 HyperChanger 在本地存储、功能运行、网络请求及系统权限方面的数据处理方式。HyperChanger 无需注册账号，不内置商业广告或用户行为统计 SDK，也不会建立商业用途的用户画像；当你启用或触发联网功能时，应用会向对应服务方发起必要的网络请求。

## 1. 本地存储与进程间同步

1.1 你的界面设置、作用域配置、导入的图片/视频/歌词/音效、预设文件以及运行缓存均保存在设备本地。为使已启用的 Hook 在系统或目标应用内生效，必要配置与素材会通过框架提供的远程偏好（Remote Preferences）或应用内 ContentProvider 等本机进程间机制同步至目标进程。这类同步仅发生在设备本地进程之间，不会上传至云端服务器。

1.2 当你通过文件、二维码或系统分享导入、导出配置时，由你自行选择保存位置或接收方；本软件不会在后台自动将配置或个人素材备份至云端。你所选用的外部存储或分享渠道受其自身隐私政策约束。

## 2. 功能运行时的数据读取

2.1 仅在你启用对应功能且目标进程处于作用域内时，模块才会在本机进程内读取通知内容、应用信息、媒体标题、歌手、专辑、时长、封面、播放状态及交通/取餐卡片信息，用于界面展示、匹配与交互。请注意，部分内容可能会在锁屏等可见界面显示，请按需在设置中调整隐私与可见范围。

2.2 当你授予日历权限并开启锁屏日程显示时，应用会读取必要的日程信息（如事件标题、开始时间和全天状态）供本地展示。读取已安装应用列表仅用于模块内的作用域提示、应用选择与底部导航适配列表。

2.3 开启传送门增强 OCR 后，待识别图像通过本机接口交由应用内置的本地识别引擎处理，并将结果返回给传送门；识别过程无需上传图像至云端（仅在首次下载 OCR 模型文件时需联网）。目标应用自身的识别流程及后续服务仍适用各自政策。

## 3. 联网场景：在线音乐与动态内容

3.1 启用在线歌词、曲目信息或封面获取功能后，模块会向你选用的数据源发送必要的匹配参数（如歌曲名、歌手、专辑、时长、歌曲标识或资源链接）。可能访问的服务包括网易云音乐、QQ 音乐、酷狗音乐、酷我音乐、LRCLIB、AMLL/TTML 歌词库、Apple Music / iTunes、MusicBrainz 及其 CDN 或镜像节点，实际请求取决于你开启的功能与来源设置。

3.2 使用交通卡片素材或可选的云端取餐规则功能时，可能会向 HeyTap / ColorOS 相关资源接口发起请求。交通素材请求路径中可能包含所选城市或地标名称，云端规则请求可能包含 Android API 版本等客户端信息，请结合自身隐私需求决定是否开启。

## 4. 联网场景：更新、资源与外部链接

4.1 检查更新、下载安装包、加载贡献者列表与头像、获取在线设备参数预设、获取在线快门音效或下载本地 OCR 模型时，应用会访问 GitHub、GitHub Pages、GitHub Raw、Gitee 或资源链接对应的托管服务。

4.2 应用启动时会自动从 GitHub Pages（失败时尝试 Gitee）刷新公开的 BOSE 调音支持机型列表。该过程仅下载公开的静态列表文件，不会上传你本机的设备代号或硬件标识。

4.3 点击官网、项目仓库、交流群组或赞助支持等外部链接时，将交由系统浏览器或对应应用打开，后续的网络与数据处理由相应平台负责。如果你主动向仓库提交预设、发起 Issue 或公开分享日志，所提交的内容将对公众可见。

## 5. 网络连接信息说明

5.1 向上述外部服务、托管平台或 CDN 发起请求时，对方服务器按照常规互联网通信方式，可获取请求来源 IP 地址、访问时间、请求路径、查询参数及 User-Agent 等连接信息（部分请求包含模块版本或 Android API 版本）。本软件不会主动在请求中附带 IMEI、Android ID、通讯录或账号密码等无关隐私信息，但第三方服务会依据各自政策保留日志或处理访问记录。

## 6. 权限与 Root 能力说明

6.1 Root 与框架能力：用于运行环境检测、配置写入与同步、目标进程操作（如重启作用域应用）、诊断日志读取，以及你主动发起的静默更新安装。启用模块即允许相关 Hook 在所选目标进程内执行，请谨慎授予 Root 权限与配置作用域。

6.2 系统权限用途：文件与媒体选择用于导入或导出图片、视频、歌词及预设；壁纸权限用于光栅动态壁纸等功能；查询所有应用权限用于生成目标应用与适配列表；通知权限用于相关状态提示；日历权限用于锁屏日程展示；安装未知应用权限用于你在应用内触发的更新安装；开机事件用于重启后初始化相关状态。你可以在系统设置中随时管理或撤销这些权限。

## 7. 日志、数据保留与清理

7.1 诊断日志仅在本地生成。导出或分享日志包时，其中可能包含系统环境信息（environment.txt）、通知内容、应用包名或媒体记录；在发送给他人或发布至公开平台前，请务必检查并剔除个人敏感信息。

7.2 本地设置与导入文件会保留至你主动删除、清除应用数据或卸载本软件为止；缓存数据也可能被系统自动清理。需注意，你主动导出至公共目录的文件、其他目标应用的缓存、框架保存的配置副本以及第三方服务留存的记录不会随卸载自动删除，如需彻底清除请分别处理。

## 8. 你的控制权与政策更新

8.1 你可以随时关闭不需要的功能开关、撤销系统权限、在模块管理器中停用作用域或卸载本软件。如需彻底阻止应用联网，可在系统设置中禁用其网络权限或在离线环境下使用（对应的在线资源与更新功能将同步不可用）。

8.2 本政策会随功能迭代同步更新，并在页面顶部标注修订日期。如果你对隐私处理有任何疑问，欢迎前往 https://github.com/ColdP/HyperChanger 的 Issue 反馈（公开提问前请勿附带敏感个人信息）。

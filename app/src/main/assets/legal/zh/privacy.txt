HyperChanger 隐私与数据保护政策

生效日期：2026年9月19日
最近修订：2026年9月19日

HyperChanger 项目高度尊重并重视用户的个人隐私与数据安全。本软件遵循本地优先、数据最小化与高度透明的技术原则。本《隐私与数据保护政策》（以下简称“本政策”）详细阐明了本软件在运行过程中涉及的数据处理方式、系统权限使用目的以及用户的权利控制。

一、基本数据处理原则与本地存储架构
1.1 纯本地运行架构：维护团队未设立、未运营任何用于收集、汇聚或回传用户设备指纹、身份识别码或操作行为数据的中心化服务器。
1.2 配置偏好信息：你在应用内配置的所有界面参数、材质模糊度、布局开关、小组件设置等，均仅保存于 Android 系统分配给本软件的本地私有沙盒存储区（Shared Preferences 目录），不会通过后台私自上传至远程服务器。
1.3 用户本地素材与配置文件：
第一，用户自行导入的卡片背景图片、设备 Logo 图标、个性化视频及导出的 JSON 预设文件，均完全存放于设备本地存储空间；
第二，用户在本地创建、导入、编辑或备份的歌词库文件（LRC 或 TTML 格式），仅供本软件在本地解析并供给锁屏播放器渲染，绝不在未经用户授权的情况下向任何云端同步。

二、外部网络交互与数据传输场景的充分披露
本软件的核心功能及系统 Hook 逻辑均在离线状态下运行。仅在以下两项特定功能被触发时，软件才会发起受限的网络通信：
2.1 锁屏在线歌词检索功能
当且仅当用户在 HyperOS 4 系统锁屏界面播放音乐，且在模块设置中主动开启了“在线检索匹配歌词”功能时触发。
通信内容限定：本软件仅抓取当前正在播放的媒体元数据，即音频标题（Title）、艺术家名称（Artist）及所属专辑名（Album），通过加密传输通道（HTTPS）向公开歌词 API（如 LRCLIB API 或 AMLL TTML 公共检索库）发送查询请求。
隐私边界承诺：该检索请求严格遵循最小必要原则，绝不携带设备唯一硬件标识符（如 IMEI、MEID、MAC 地址、Android ID、OAID、ICCID）、地理位置坐标、网络通讯录或任何个人身份识别数据。
2.2 模块软件版本更新检测
当用户在“关于”界面主动点击“检查更新”，或开启了启动应用时自动检查最新版本选项时触发。
通信内容限定：客户端向开源代码托管平台（GitHub Releases API）发起标准的 HTTP 查询请求，以对比最新版本标签、拉取更新日志文本以及获取安装包的官方下载直链。
隐私边界承诺：该请求仅包含网络通信所必须的标准 HTTP 标头（如 IP 地址与客户端 User-Agent），维护团队不会利用上述访问日志对特定用户的真实身份进行画像或行为追踪。

三、高级系统权限调用规范与边界限制
为了在 HyperOS 4 深度定制系统中实现功能配置与界面接管，本软件需在特定场景下申请并使用以下系统权限，其使用边界严格限定如下：
3.1 最高管理员权限（Root 权限）
使用边界：Root 权限仅用于在用户更改模块设置后，由用户主动触发“重启作用域”指令。软件通过执行局部的系统终端命令（如杀除特定应用进程号），促使 System UI、相册插件或输入法进程重新加载以应用新的 Hook 配置。
安全保证：本软件绝不会在后台利用 Root 权限越权扫描用户的私有存储分区、静默篡改其他第三方应用程序数据、修改系统安全策略或植入特权驻留后门。
3.2 外部存储与媒体访问权限
使用边界：该权限仅在用户主动进行文件选取与写出操作时激活，具体用途为：读取用户自主指定的背景图片或矢量素材、导入或导出模块预设配置 JSON 文件、扫描用户自主选择的二维码图片，以及导入或导出本地歌词库数据。
安全保证：本软件绝不利用存储权限越权遍历、检索或读取用户存放在存储设备中的私人相册照片、工作文档、聊天备份等无关文件。
3.3 网络通信权限
使用边界：仅用于本政策第二条明确披露的在线歌词检索功能与 GitHub 软件版本更新检测。若用户在模块设置中停用上述两项功能，本软件即可在完全离线断网的状态下正常使用。

四、第三方商业 SDK 与分析追踪组件零集成承诺
4.1 商业 SDK 零存在：本软件源代码完全开放透明，内部绝未集成任何第三方商业广告分发 SDK、金融征信组件，亦未集成任何商业化用户行为分析与统计 SDK（如友盟统计、TalkingData、Google Firebase Analytics 等）。
4.2 无数据转让与共享：维护团队不会将使用过程中涉及的任何数据出售、出租、转让或共享给任何商业数据经纪商、广告营销机构或第三方实体。

五、用户提交错误日志（Logcat）时的隐私保护指引
5.1 当用户在 HyperOS 4 环境下遭遇功能异常并向维护团队提交 Logcat 日志时，请务必注意：Android 系统的原生全局日志缓存可能包含系统正在展示的通知文本、正在运行的应用包名甚至剪贴板片段。
5.2 用户负有在提交日志前进行人工脱敏的法定义务。在将日志发布到 GitHub Issue 或公开社交平台之前，用户必须自行审查日志内容，剔除其中可能涉及的个人姓名、电话号码、真实 IP 地址、账号 Token 及其他敏感个人隐私数据。

六、用户对个人数据的完全控制与销毁机制
6.1 离线降级选择权：用户可随时在应用设置内彻底关闭在线歌词匹配及检查更新开关，本软件将立即切断所有外部网络连接，转为纯离线运行模式。
6.2 数据彻底销毁权：用户可随时通过系统设置内的“清除存储空间与缓存”选项，清空本软件在设备本地沙盒中保存的所有偏好设置。用户在卸载本软件后，除用户主动导出至公共目录的 JSON 或歌词备份外，本软件在设备内部创建的所有配置数据将立即被操作系统彻底物理销毁。

七、隐私政策的修订与联络
7.1 随着 HyperOS 4 系统的更新迭代或本软件功能的完善，维护团队可能会适时对本政策进行局部修订。修订后的隐私政策将在随附版本的发布说明中向用户公示。
7.2 若你对本政策内容、数据处理逻辑或权限使用存在任何疑问、意见或监督诉求，可通过本软件在 GitHub 的官方开源仓库提交带有 Privacy 标签的 Issue 进行反馈与沟通。

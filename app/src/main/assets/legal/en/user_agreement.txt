HyperChanger User Agreement

Effective date: November 1, 2026
Last revised: November 13, 2026

Welcome to HyperChanger ("the software"), an open-source Xposed module for Xiaomi HyperOS 4 (compatible with Vector, LSPosed, and similar frameworks) designed to customize the appearance and behavior of the system UI and supported apps. Before enabling the module, please read this Agreement, the Disclaimer, and the Privacy Policy to understand compatibility requirements, data handling, and device risks.

## 1. Acceptance and Usage

1.1 Checking the agreement box and entering the verification code during onboarding confirms that you have read and understood these documents. If you do not agree to the terms, do not enable the module in your manager; if it is already active, disable it first and then uninstall it if needed.

1.2 Installing the app does not automatically enable all features. Whether hooks take effect depends on the framework connection status, selected scopes, and individual feature toggles; some settings require restarting the target app or rebooting the device.

## 2. Environment and Safe Operation

2.1 The software is primarily built and tested for specific HyperOS 4 (Android 17) builds. Compatibility is not guaranteed across all devices, regional variants, beta releases, or future system updates. MIUI, HyperOS 1–3, other OEM systems, AOSP, and unverified custom ROMs are not supported.

2.2 Module features require root access and a compatible Xposed framework, which generally involves unlocking the bootloader. Make sure you know how to manage scopes, back up data, disable modules, and recover your device. Do not enable the module if you cannot handle startup failures or crashes on your own.

2.3 Enable only the scopes you actually need. Back up important data before modifying critical system options or installing system updates, and recheck compatibility afterward. If issues occur, disable the affected feature or module before troubleshooting.

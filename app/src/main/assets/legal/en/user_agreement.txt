Welcome to HyperChanger (the software), an open-source LSPosed module that changes system and application interfaces and behavior on Xiaomi HyperOS 4. Before enabling it, read this agreement, the Disclaimer, and the Privacy Policy, especially the compatibility, data handling, and device recovery information.

## 1. Reading and acceptance

1.1 Decide whether to use the software after understanding these documents. The setup checkbox and verification code confirm reading; they grant no additional permissions and do not waive rights that cannot legally be waived. If you disagree, do not enable the module; disable an active module before uninstalling it if needed.

1.2 Installing the app does not enable every feature. Operation depends on the framework, scopes, and individual settings. Some changes require the target process to reload.

## 2. Environment and safe use

2.1 The software targets specific HyperOS 4 builds. Compatibility is not guaranteed for every device, regional build, beta, or future update. MIUI, HyperOS 1–3, other manufacturers' systems, AOSP, and unverified custom ROMs are unsupported.

2.2 Module features require a compatible LSPosed framework and environment, generally involving bootloader unlocking and root. Understand scopes, backups, disabling modules, and recovery. Do not enable the module if you cannot handle startup failures independently.

2.3 Enable only the scopes you need. Back up important data before changes and recheck compatibility after system updates. If problems occur, disable the relevant feature or module before investigating conflicts.

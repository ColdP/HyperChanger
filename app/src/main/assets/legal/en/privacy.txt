HyperChanger Privacy and Data Protection Policy

Effective date: September 19, 2026
Last revised: September 19, 2026

This policy explains how HyperChanger handles information. The project follows local-first processing, data minimization, and transparency principles.

1. Local storage

HyperChanger does not operate a central service that collects device fingerprints, identity numbers, or usage behavior. Settings, appearance choices, material values, widget configuration, and other preferences are stored in the app's private Android storage. Imported images, videos, logos, JSON presets, and lyric files remain on the device unless you deliberately export or share them. The app does not silently upload these files.

2. Optional network communication

Core hooks and configuration work offline. Network access is limited to features that you enable or request:

• Online lyric lookup sends the currently playing title, artist, and album to the selected public lyric service over HTTPS. It does not intentionally send IMEI, MEID, MAC address, Android ID, OAID, ICCID, location, contacts, or account credentials.
• Update checking requests release metadata, notes, and download links from GitHub or the configured update service. Normal network information such as IP address and User-Agent is handled by the network provider. The project does not use it to identify or profile you.

You may disable online lyric lookup and automatic update checks. The app can then operate without these network requests.

3. Permissions and privileged access

Root access is used only for user-initiated scope restart or related configuration actions. The app does not use root to silently search private storage, alter unrelated app data, weaken security controls, or install a persistent backdoor. File and media access is limited to files you select for import, export, preview, or sharing. Network permission is used only for the services described above.

4. No advertising or analytics

The open-source project does not include advertising SDKs, commercial analytics, credit-scoring components, or behavioral tracking libraries. The maintainers do not sell, rent, trade, or share app data with data brokers, advertisers, or unrelated third parties.

5. Logs and user-submitted content

Android logs may contain notification text, package names, clipboard fragments, account names, addresses, tokens, or other sensitive information. Before submitting a log to GitHub or another public place, you are responsible for reviewing and redacting personal data. Information you voluntarily post publicly may be visible to others and is governed by that service's policy.

6. Control and deletion

You can turn off optional online functions at any time. Clearing the app's storage removes its local preferences and private files. Uninstalling removes app-private data, except files you deliberately exported to shared storage or another service. You control whether those exported files remain.

7. Changes and contact

This policy may change when HyperOS, project features, or legal requirements change. The current version is included with the application and release notes. Questions or privacy concerns may be raised through the project's public GitHub repository.

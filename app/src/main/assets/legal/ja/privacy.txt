HyperChanger プライバシーポリシー

施行日：2026年11月1日
最終改定日：2026年11月1日

本ポリシーはデータの用途、端末内保存、通信と利用者の選択を説明します。HyperChanger はアカウント登録を要求せず、広告や商用行動分析のための利用者プロフィールを作成しません。ただし通信機能は提供先にリクエストと必要なパラメーターを送信します。

## 1. 設定とローカルファイル

1.1 画面設定、スコープ関連設定、画像、動画、歌詞、プリセット、取得資源、キャッシュは主に端末内に保存します。必要な設定や素材は、選択した機能の実行のため、フレームワークのリモート設定や端末内インターフェースで有効な対象プロセスに渡します。ここでいうリモート設定は端末内のプロセス間同期であり、クラウド同期ではありません。

1.2 インポート、エクスポート、共有には選択したファイル、QR コード、システム共有先を使用します。設定や個人素材をクラウドバックアップとして自動送信しません。受信アプリや選択したクラウドストレージには別のデータ方針がある場合があります。

## 2. 機能実行時のデータ

2.1 有効な通知、アイランド、ロック画面、メディア機能は、表示、照合、操作のため、対象プロセス内で通知内容、アプリ情報、曲名、アーティスト、アルバム、再生時間、アートワーク、再生状態、交通・受取カード情報を読み取る場合があります。ロック画面など他人から見える場所に表示されることがあるため、表示範囲を調整してください。

2.2 カレンダー権限と該当する予定表示を有効にした場合、予定名、開始時刻、終日状態などの必要情報を読み取り、端末内に表示します。アプリ一覧はスコープ、対象アプリの選択や関連設定に利用し、広告プロフィール用には送信しません。

2.3 拡張 OCR は端末内インターフェースで画像をローカル認識エンジンへ渡し、結果をポータルへ返します。モデルのダウンロードに認識対象画像の送信は不要です。対象アプリ本来の認識処理や、その後利用するサービスには各自のポリシーが適用されます。

## 3. 通信：音楽と動的コンテンツ

3.1 オンライン音楽機能を有効にすると、曲名、アーティスト、アルバム、時間、曲 ID、資源 URL などの照合情報を、選択された歌詞・曲情報・アートワークの提供先へ送ります。提供先には NetEase Cloud Music、QQ Music、Kugou、Kuwo、LRCLIB、AMLL/TTML、Apple Music/iTunes、MusicBrainz や各 CDN・ミラーが含まれる場合があります。実際の通信は機能と取得元によります。

3.2 交通カード画像やクラウド受取ルールなどでは HeyTap/ColorOS 等のサービスに接続する場合があります。交通素材のパスに都市やランドマーク名が含まれ、行程に関連する地域が推測される可能性があります。クラウドルールのリクエストには Android API 版などのクライアント情報を含む場合があります。完全な匿名通信ではありません。

## 4. 通信：更新、資源、外部リンク

4.1 更新確認・更新パッケージ取得、貢献者一覧・アイコン、オンライン端末プリセット、OCR モデル取得では GitHub Pages、GitHub/GitHub Raw、Gitee や資源 URL の提供先に接続します。

4.2 アプリ起動時に BOSE 対応端末一覧を更新し、GitHub Pages を優先して、失敗時は Gitee を試します。公開一覧のダウンロードであり、端末自身のコード名の送信は不要です。歌詞や更新確認をオフにしても、すべての通信が止まるわけではありません。

4.3 リポジトリ、サイト、グループ、支援リンクはブラウザーや別アプリで開き、そのサービスが通信・データを処理します。プリセットの提供、Issue の投稿、ログ共有では、選択して送った内容が公開される場合があります。

## 5. 接続情報と第三者の処理

5.1 サービス、経由 CDN、ミラーは送信元 IP、アクセス時刻、パス、検索パラメーター、User-Agent 等を知ることができます。一部はモジュール版や Android API 版を含みます。IP は接続情報であり、本ソフトウェアが追加した識別フィールドではありません。提供元は各自の方針でログを保存し、異なる地域でデータを処理する場合があります。

5.2 資源取得は IMEI、Android ID、連絡先、アカウントのパスワードの収集を目的としません。商用広告・行動統計 SDK を組み込まず、個人データを販売しません。ただし第三者がアクセスを記録しないという意味ではなく、自ら送るファイルや報告も対象外です。

## 6. 権限とシステム機能

6.1 Root とフレームワークの権限は環境確認、設定反映、対象プロセス操作、ログ取得、利用者が選ぶインストール等に用い、スコープの再起動だけに限りません。有効化すると選択した対象プロセスで Hook が動作します。スコープと管理者権限は慎重に付与してください。

6.2 ファイル選択は指定画像・動画・歌詞・プリセットの入出力に使用します。壁紙権限は壁紙機能、アプリ照会はアプリ選択、通知権限は状態表示、カレンダー権限は予定表示、パッケージインストール権限は利用者が開始する更新、起動イベントは該当機能の初期化に使用します。権限の可否と取り消しはシステムで管理します。

## 7. ログ、保存と削除

7.1 診断ログを端末内に生成する場合があります。取得・出力・共有するログには通知、パッケージ名、メディア情報等が含まれる可能性があります。送信先を決める前に認証情報、アカウント、連絡先、行程等を確認・削除してください。公開 Issue は検索・複製される場合があるため、秘密情報を投稿しないでください。

7.2 設定や取込ファイルは通常、変更、削除、データ消去、アンインストールまで保存します。キャッシュはシステムが消す場合もあります。データ消去やアンインストールは通常アプリ私有データを除去しますが、物理的な復元不能を保証しません。公共領域への出力、他の対象アプリのキャッシュ、フレームワーク内の複製、第三者の記録は自動削除されず、別途管理が必要です。

## 8. 選択とポリシーの更新

8.1 不要な機能をオフにし、権限を取り消し、スコープを無効化し、またはアンインストールできます。すべての通信を防ぐにはシステムの通信制御やオフライン環境を使用し、通信機能が使えなくなることをご了承ください。一つのスイッチで他機能や送信済みのリクエストが直ちに止まるわけではありません。

8.2 機能の変化に合わせて本文と改定日を更新します。プライバシーに関する質問は https://github.com/ColdP/HyperChanger の Issue へお寄せください。通常は公開のため、機密性の高い個人情報を含めないでください。

HyperChanger プライバシーポリシー

施行日：2026年11月1日
最終改定日：2026年11月13日

本プライバシーポリシーは、HyperChanger における端末内保存、機能実行時のデータ処理、ネットワーク通信、およびシステム権限の扱いについて説明します。HyperChanger はアカウント登録不要で利用でき、商用広告や行動分析用の SDK を組み込んでおらず、営利目的のユーザープロファイルを作成しません。オンライン機能を有効化または実行した場合にのみ、必要なネットワークリクエストが各提供元へ送信されます。

## 1. ローカル保存とプロセス間同期

1.1 画面設定、スコープ設定、インポートした画像・動画・歌詞・音声、プリセット、および実行キャッシュは端末内に保存されます。有効化された Hook がシステムや対象アプリ内で動作するよう、必要な設定や素材はフレームワークの「リモート設定（Remote Preferences）」やアプリ内の ContentProvider といった端末内プロセス間通信により対象プロセスへ受け渡されます。これは端末内部での同期であり、クラウドサーバーへアップロードされることはありません。

1.2 ファイル、QR コード、またはシステム共有機能を通じて設定をインポート・エクスポートする際は、保存先や送信先をご自身で選択します。本ソフトウェアがバックグラウンドで設定や個人素材を自動的にクラウドバックアップすることはありません。選択した外部ストレージや共有先アプリには、それぞれのプライバシーポリシーが適用されます。

## 2. 機能動作時に読み取るデータ

2.1 対応機能が有効であり、かつ対象プロセスがスコープに含まれている場合に限り、モジュールは表示・照合・操作のために通知内容、アプリ情報、曲名、アーティスト、アルバム、再生時間、アートワーク、再生状態、および交通・受取カード情報を対象プロセス内で読み取ります。一部はロック画面など周囲から見える場所に表示されるため、必要に応じて設定からプライバシー表示範囲を調整してください。

2.2 カレンダー権限を許可してロック画面の予定表示を有効にすると、端末内での表示に必要な予定情報（タイトル、開始時刻、終日設定など）を読み取ります。インストール済みアプリ一覧の読み取りは、スコープ案内の表示、アプリ選択、および下部ナビゲーション対応リストの生成にのみ使用します。

2.3 ポータル拡張 OCR を有効にした場合、認識対象の画像データは端末内インターフェースを通じて内蔵のローカル認識エンジンに渡され、結果のみがポータルへ返されます。認識時に画像をクラウドへ送信することはありません（OCR モデルファイルの初回ダウンロード時のみ通信が必要です）。対象アプリ本来の認識処理や、その後に利用するサービスには各社のポリシーが適用されます。

## 3. 通信が発生する場面：オンライン音楽と動的コンテンツ

3.1 オンライン歌詞、曲情報、またはアートワーク取得を有効にすると、選択した音楽データ提供元へ照合に必要なパラメーター（曲名、アーティスト、アルバム、時間、曲 ID、リソース URL など）を送信します。接続先には、有効な機能や設定に応じて NetEase Cloud Music、QQ Music、Kugou、Kuwo、LRCLIB、AMLL/TTML リポジトリ、Apple Music / iTunes、MusicBrainz および各 CDN・ミラーが含まれる場合があります。

3.2 交通カード素材や任意のクラウドルール取得を利用する場合、HeyTap / ColorOS 関連のリソースインターフェースへリクエストを送信することがあります。交通素材のパスには選択した都市名やランドマーク名が含まれる場合があり、クラウドルール取得には Android API バージョンなどのクライアント情報が含まれることがあります。ご自身のプライバシー基準に合わせてご利用をご判断ください。

## 4. 通信が発生する場面：更新、リソース、外部リンク

4.1 アップデート確認、APK 取得、貢献者一覧やアイコンの読み込み、オンライン端末プリセットの閲覧、オンラインシャッター音の取得、およびローカル OCR モデルのダウンロード時には、GitHub、GitHub Pages、GitHub Raw、Gitee、またはリソース URL の提供元サーバーへ接続します。

4.2 アプリ起動時には、GitHub Pages（失敗時は Gitee）から公開されている BOSE チューニング対応機種一覧を自動更新します。これは公開用リストファイルのダウンロードのみを行い、お使いの端末コードネームやハードウェア識別子を送信することはありません。

4.3 公式サイト、プロジェクトリポジトリ、コミュニティグループ、寄付ページなどの外部リンクをタップすると、ブラウザーまたは該当アプリで開かれ、その後の通信やデータ処理は各プラットフォームの規約に従います。また、端末プリセットの投稿、Issue の作成、ログの共有を自ら行った場合、送信内容は一般公開されます。

## 5. ネットワーク接続情報の取り扱い

5.1 上記の外部サービス、ホスティング基盤、または CDN へリクエストを送信する際、相手先サーバーは一般的なインターネット通信の仕組み上、接続元 IP アドレス、アクセス時刻、リクエストパス、クエリパラメーター、User-Agent（一部にはモジュールバージョンや Android API バージョンを含む）を受け取ります。本ソフトウェアから IMEI、Android ID、連絡先、アカウントパスワードなどの無関係な情報を付与することはありませんが、接続先プラットフォームが各自の方針に基づきアクセスログを保存・処理する場合があります。

## 6. 権限と Root 権限の用途

6.1 Root およびフレームワーク権限：動作環境のチェック、設定の書き込みと同期、対象プロセスの操作（スコープ対象アプリの再起動など）、診断ログの読み取り、およびユーザーが開始したサイレントアップデート実行に使用します。モジュールを有効化すると選択したスコープ内で Hook が動作するため、Root 権限とスコープは慎重に管理してください。

6.2 システム権限の用途：ファイル・メディアアクセスは画像、動画、歌詞、プリセットの入出力に、壁紙権限はラスターライブ壁紙などの機能に、全アプリ照会権限は対象アプリやナビゲーション対応リストの生成に、通知権限は状態通知に、カレンダー権限はロック画面の予定表示に、パッケージインストール権限はアプリ内更新の実行に、起動完了イベントは再起動後の初期化に使用します。これらの権限はシステム設定からいつでも取り消すことができます。

## 7. ログ、データの保持と削除

7.1 診断ログは端末内でのみ生成されます。エクスポートしたログ ZIP には端末環境情報（environment.txt）、通知内容、アプリパッケージ名、メディア情報などが含まれる可能性があるため、他者への送信や公開前には必ず機密情報を取り除いてください。

7.2 端末内の設定や取り込んだファイルは、ご自身で削除するか、アプリデータの消去またはアンインストールを行うまで保持されます（キャッシュはシステムにより自動削除される場合があります）。なお、公開ディレクトリへエクスポートしたファイル、他の対象アプリのキャッシュ、フレームワーク側が保持する設定コピー、および外部サーバー上のアクセス記録はアンインストール時に自動消去されないため、必要に応じて個別に管理してください。

## 8. 利用者の管理権とポリシーの更新

8.1 不要な機能スイッチをオフにする、システム権限を取り消す、モジュールマネージャーでスコープを外す、あるいは本ソフトウェアをアンインストールすることがいつでも可能です。すべての通信を完全に遮断したい場合は、システム設定からネットワーク権限を制限するかオフライン環境でご利用ください（オンライン機能や更新確認は利用できなくなります）。

8.2 本ポリシーは機能の変更に合わせて随時更新され、ページ上部に最終改定日を記載します。プライバシーに関するお問い合わせは https://github.com/ColdP/HyperChanger の Issue までお寄せください（公開の場となるため、機密性の高い個人情報は記載しないでください）。
